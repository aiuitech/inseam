# docs.inseam.io

The inseam documentation site: [Astro Starlight](https://starlight.astro.build) deployed to Cloudflare Workers on the docs.inseam.io custom domain.

**There is no authored content in this app.** `scripts/sync-content.mjs` (run automatically before `dev` and `build`) copies the repo's `../../docs` tree into `src/content/docs/`, lifting each page's `# ` heading into Starlight frontmatter and rewriting intra-docs links. Edit `../../docs` — see `docs/doc-generation.md` for the whole pipeline, including the pages that are themselves generated from source by `cargo xtask docs`.

`llms.txt` / `llms-full.txt` / `llms-small.txt` are emitted at build time by the `starlight-llms-txt` plugin. The sidebar is autogenerated from the docs tree.

## Commands

| Command | Action |
| :--- | :--- |
| `pnpm dev` | Sync content and start the dev server |
| `pnpm build` | Sync content and build to `./dist/` |
| `pnpm deploy` | Build and deploy via `wrangler deploy` |
