# Indexing

How a node turns sources into a searchable index: [connections](connections.md) are how the node reaches its hosts — the [filesystem host](filesystem-host.md) is the first, [Google Workspace](google-workspace.md) the first remote one, the [web host](web-host.md) the fetch-only one that lets links be followed, the [GitHub host](github-host.md) the first loaded (WASM) one, the [call capture host](call-capture-host.md) the one that joins a phone call and archives it — and list what exists, [transforms](transforms.md) break sources into fragments, [embeddings](embeddings.md) covers the embedder — model, width, which fragments get vectors, local models — [storage](storage.md) holds the catalog, graph, and search tables, [maintenance](maintenance.md) covers the sweep that keeps the index matching both reality and the configuration, [vocabulary](vocabulary.md) covers the corpus's own words — mined, anchored, clustered, and grounded after every file has landed — and the facets hosts put on envelopes, and [ignore](ignore.md) covers keeping sources out of the node entirely.
